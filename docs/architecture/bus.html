The bus and the aos command

How sessions find each other, message each other and start work, and how a message gets into an agent.

aos send

What the command does

While AgentOS restarts

Key states

delivered
It reached the recipient.
queued
The agent was busy; it sees it after its turn.
FAILED
Not delivered; the reason is printed and the exit code is 2.

In plain words

Renaming a session keeps its old names, so a message to the old name still reaches it; if another session has taken that name, the current owner wins and the command says so.

Messages from the orchestrator or a schedule are labelled as such and never count as your approval.
