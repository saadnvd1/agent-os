Machines and moves

Link another machine that runs AgentOS and its sessions sit beside yours. A task can start there, or be carried there and back.

Linking, and how a remote session reaches you

Move a task

Placement by the queue

Key states

moving
Leaving: nothing can sign it off and a second move is refused.
moved
The other machine has it; this row is kept.
running
Back running here if the target refused.

In plain words

Work that needs a Mac never leaves it, and a task already running is never placed elsewhere by the queue. Plan-only, plan-first, pinned and non-Claude tasks stay on this machine and wait.

Tasks waiting on you (an escalated gate or an open ask), card tasks and stacked tasks don't move yet.
