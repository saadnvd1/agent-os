Key states

trusted
This machine, or your tailnet.
paired
Holds a device token.
can approve
A paired device that may answer asks and switch Away.
unpaired
Refused.

In plain words

Notifications are skipped while you have been using the computer in the last few minutes, and with Away on everything except asks folds into a digest. Browsers can't receive pushes from AgentOS; only the app can.

Connect is for reach, not for trust: a request that arrives through it still needs a paired device.

Key files

  • app/pair/page.tsx the pairing page
  • lib/connect/serve.ts Connect on the machine
  • lib/connect/control-api.ts talking to the Connect service
  • lib/notify/push/outbox.ts the push outbox
  • lib/notify/push/policy.ts what is pushed, and when not
  • lib/intake what a phone sends to an orchestrator
