# Guides

How-to guides for using AgentOS, in reading order.

1. [Install AgentOS](install.md): requirements, the one-line install, first-run setup, Windows, supported agents, signing in your agents, running it as a service, and reaching it from other devices.
2. [Using AgentOS from your phone](phone.md): add your machine in the iPhone app, pair it, reach it from anywhere with Connect, and get notifications.
3. [Sessions and the sidebar](sessions.md): start a session or task from a draft, read the sidebar, and watch the machine's load.
4. [Chat](chat.md): the streaming chat, plans, attachments and the agent's own terminal.
5. [Tasks](tasks.md): work that ends in a pull request, queued tasks, stacks and plans in pieces.
6. [Schedules and recipes](schedules.md): start work on a timer, or save a job that comes up again.
7. [Agent network](agent-network.md): sessions that message each other with `aos`.
8. [Sharing](sharing.md): a read-only link to a chat or a page, checked and masked first, or downloaded as HTML.
9. [Export for AI](export.md): a session or a range of its turns as Markdown, JSON or HTML for another model, with a compact mode, masking and a size estimate.
10. [Local models](local-models.md): run a model you host through Pi or OpenCode, turn on tool calling in its server, and what "Ended early" means.
11. [Tips and What's New](tips.md): the lightbulb and sparkle in the sidebar, what a tip is, and how to turn tips off.
12. [Getting around](navigation.md): each chat reopens where you left it, what is new since, and back and forward between chats.

How each part works in detail is in [the reference docs](https://github.com/saadnvd1/agent-os/tree/main/docs/reference).
